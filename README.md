# Distribuição dos projetos de infectologia

Esta branch contém apenas tarballs prontos para download. Não é código-fonte versionado.

Conteúdo:

- `hospital-virtual-infecto.tar.gz` — Next.js + Claude para gerar evolução infectológica
- `cockpit-infecto.tar.gz` — Streamlit local para casos, evolução, produtividade
- `radar-evidencias.tar.gz` — Streamlit local para PubMed/RSS/CT.gov/preprints
- `atualizador-protocolos.tar.gz` — Streamlit local para base de conhecimento + RAG simples

Veja a conversa do Claude para os comandos de extração e execução em cada um.
